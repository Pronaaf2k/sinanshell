## Instructions for your TA

### Compilation

My shell uses Python 3.8 or newer and only the Python standard library. No compilation step or package installation is required. An optional syntax check is:

```bash
python3 -m py_compile pith.py
```

### Running my shell

After retrieving the desired revision from SCCS, run:

```bash
python3 pith.py
```

For an ASCII interface without color, run:

```bash
python3 pith.py --plain
```

### Input format

Commands use a program name followed by arguments. Quotes protect spaces. External programs can be connected with `|`. Supported redirections are `<`, `>`, `>>`, `2>`, and `2>>`. `;`, `&&`, and `||` control command order. Type `help` for the supported syntax and built-ins. Built-ins run as standalone commands. This shell does not implement the full Bash scripting language.
